---
title: "REST Assured 6.3.0"
date: 2026-10-23
---

REST Assured 6.3.0 is released. It prepares for REST Assured 7.0.0, which drops Apache HttpClient 4 and Groovy from the default dependencies. Every API that 7.0.0 removes now has a replacement, the old ones are deprecated, and the new `rest-assured-openrewrite` module has a recipe that moves your code over. Among the replacements are timeouts as `Duration` in `HttpClientConfig`, `SSLContext` support in `SSLConfig` and `followRedirectsForAllMethods(..)` in `RedirectConfig`. Form authentication now also uses the config and proxy of your request for all its requests. See [Preparing for REST Assured 7.0](https://github.com/rest-assured/rest-assured/wiki/PreparingFor70), the [release notes](https://github.com/rest-assured/rest-assured/wiki/ReleaseNotes63) and the [change log](https://raw.githubusercontent.com/rest-assured/rest-assured/master/changelog.txt) for more details.
