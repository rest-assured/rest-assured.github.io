---
title: "REST Assured 7.0.0"
date: 2026-11-27
---

REST Assured 7.0.0 is released. It's a new major release. REST Assured now sends requests with the JDK's HTTP client by default, with Apache HttpClient 5 in the `http-client-apache5` module, and no longer depends on Groovy. You pick a path engine for `body(..)` paths and `jsonPath()`: `json-path-gpath`, `xml-path-gpath` or `json-path-jayway`. Java 17 is required. This release contains several non-backward compatible changes, so please read the [release notes](/release-notes/7-0/) and [which module do I need](/docs/modules/) before upgrading. The `rest-assured-openrewrite` recipe moves most code over.

Since 7.0.0-RC1, the JDK HTTP client accepts a Host header that equals the one it sends itself, and the error you get when no path engine is on the classpath links to this site. Thanks to everyone who tried the release candidate! See the [change log](https://raw.githubusercontent.com/rest-assured/rest-assured/master/changelog.txt) for more details.
