## Highlights

* REST Assured now requires Java 17+
* REST Assured now uses Groovy 5.x. While this shouldn't impact the way REST Assured works in a negative way, it required non-trivial changes under the hood to make it work.
* Support for Spring 7.x in for both the [MockMvc](/docs/spring/mock-mvc/) and [WebTestClient](/docs/spring/web-test-client/). The minimum Spring version must be 5.3+ (previously, 5.1 was required).
* Support for Jackson 3
* Support for Yasson 3 (3 is now the minimum required version)
* Support for Johnzon 2 (2 is now the minimum required version)

## Other changes

* Migrate json-path fully to Java, bypass GroovyShell for evaluation. This resolved some hairy memory leaks in certain situations.
* Stop resetting ResponseParserRegistrar during build

See [change log](https://github.com/rest-assured/rest-assured/raw/master/changelog.txt) for more details.
