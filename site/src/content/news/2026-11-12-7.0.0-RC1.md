---
title: "REST Assured 7.0.0-RC1"
date: 2026-11-12
---

REST Assured 7.0.0-RC1 is released. It's the release candidate for 7.0.0, a new major release. REST Assured now sends requests with the JDK's HTTP client by default, with Apache HttpClient 5 in the new `http-client-apache5` module, and no longer depends on Groovy. You pick a path engine for `body(..)` paths and `jsonPath()`: `json-path-gpath`, `xml-path-gpath` or `json-path-jayway`. Java 17 is required. This release contains several non-backward compatible changes, so please read the [release notes](/release-notes/7-0/) and [which module do I need](/docs/modules/) before upgrading. The `rest-assured-openrewrite` recipe moves most code over. Please try it and report what breaks! See the [change log](https://raw.githubusercontent.com/rest-assured/rest-assured/master/changelog.txt) for more details.
